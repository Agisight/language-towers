# Proposed language assessments

Upload one `<language-code>-<provider>.json` file per Pull Request using [Create Your Language](../contribute.html).

Each JSON may include `technologyScores` and lists of evidence `(comment, url)` per technology. This folder contains **unreviewed submissions**, not canonical scores. Maintainers review submissions and update `data/scores.json` separately. Do not include personal contact details or private datasets in comments.
